# Model Price Radar

> Frontier model pricing & AI company news — 19 models, 12 companies, 17 news sources, cross-validated.

Model Price Radar pulls live pricing for 19 frontier AI models from OpenRouter, plus top 3 stories per tracked source from Hacker News (community) cross-validated against official company RSS feeds (official). Updated every 6 hours. Deployed as a static GitHub Pages site.

Model Price Radar 从 OpenRouter 拉取 19 个前沿 AI 模型的实时价格，并从 Hacker News（社区）+ 各公司官方 RSS（官方）交叉验证每个被追踪来源的 Top 3 新闻。每 6 小时更新。部署为 GitHub Pages 静态站点。

---

## What's tracked

- **Pricing** — up to 20 models from 380+ on OpenRouter (quota S4/A6/B6/C4, max 2 per company); the current snapshot holds 19 from 12 companies, grouped by output price tier:
  - Tier S — Super-flagship (>$30/M output)
  - Tier A — Flagship ($10-30/M output)
  - Tier B — Mainstream ($1-10/M output)
  - Tier C — Economy (<$1/M output)
- **News** — 17 tracked sources × 3 stories max, last 7 days, cross-validated
- **Benchmarks** — Artificial Analysis intelligence / coding / speed indices, matched to 11 of the 19 tracked models. Optional, and the only part that needs a key.
- **Changelog** — last 30 days of price changes (added/removed/changed)

## Tracked sources

**Pricing (12 companies):** OpenAI · Anthropic · Google · DeepSeek · Mistral · Meta (Llama) · Qwen (Alibaba) · Moonshot (Kimi) · MiniMax · Stepfun · Perplexity · IBM Granite

**News (17 sources):** the 12 above, plus xAI · Zhipu (GLM) · NVIDIA · Meta · Alibaba.

## Data sources

The pricing, news and changelog pipeline runs on free endpoints with no credential. Only the optional benchmark fetch is authenticated.

| Source | What | Auth |
|---|---|---|
| [OpenRouter `/api/v1/models`](https://openrouter.ai) | Model pricing (pass-through) | None |
| [HN Algolia API](https://hn.algolia.com/api) | Community news | None |
| [HN Firebase API](https://hacker-news.firebaseio.com/v0/) | Cross-checking | None |
| Company blog RSS | Official news | None |
| [Artificial Analysis API](https://artificialanalysis.ai/) | Intelligence / coding / speed indices | `x-api-key` — free tier, optional |

## How it works

```
GCP systemd timer (every 6h)
  ↓
cron-stub.sh                # full run, or --dry-run / --fetch / --build
  ↓
scripts/fetch_pricing.py    → data/pricing.json
scripts/fetch_news.py       → data/news.json
scripts/fetch_benchmarks.py → data/benchmarks.json  (optional, needs key)
scripts/detect_changes.py   → data/changelog.json
scripts/build.py            → index.html
  ↓
git push → w1977-0/model-price-radar
  ↓
GitHub Pages auto-rebuild → https://w1977-0.github.io/model-price-radar/
```

```
    ├── changelog.json       # 30-day change history

```

## Local run

```bash
python3 scripts/fetch_pricing.py
python3 scripts/fetch_news.py
python3 scripts/detect_changes.py
python3 scripts/build.py
# open index.html in browser
```

The benchmark step is optional and is the only one that reads a credential:

```bash
export AA_API_KEY=...        # free tier, 1000 requests/day
python3 scripts/fetch_benchmarks.py
python3 scripts/build.py     # re-run so the page picks the indices up
```
